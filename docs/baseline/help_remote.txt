Manage snapshot remotes (list, add, remove)

Usage:
  tsnap remote list
  tsnap remote add <name> s3 --endpoint=URL --bucket=NAME --region=REGION --key=KEY --secret=SECRET [--path-style]
  tsnap remote remove <name>
Manage snapshot remotes. 'list' shows configured remotes. 'add' registers a new remote. 'remove' deletes it.

Examples:
  tsnap remote list
  tsnap remote add origin s3 --endpoint=https://s3.example --bucket=mybucket --region=us-east-1 --key=AKIA... --secret=...
  tsnap remote remove origin
