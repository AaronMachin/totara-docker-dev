Manage background snapshot hosting tunnel (start/status/logs/stop)

Usage: tsnap host [start|status|logs|stop] [--bucket=NAME --region=REG --port=8000 --key=K --secret=S | --anon] [--prefix=P] [--endpoint=URL] [--timeout=SEC] 
Starts or manages background host (tunnel or provided endpoint). 'start' is default.

Examples:
  tsnap host
  tsnap host status
  tsnap host logs
  tsnap host stop
  tsnap host --bucket=mybucket --region=us-east-1 --port=9000 --anon
