Fetch (refresh) remote snapshot metadata cache

Usage: tsnap fetch [--remote=name1,name2|--all] [--limit=N] [--stale-only]
Refresh local cache of remote snapshot metadata. Without --remote or --all it fetches all non-local remotes.

Examples:
  tsnap fetch --all
  tsnap fetch --remote=origin,backup
  tsnap fetch --stale-only
  tsnap fetch --limit=500 --all
